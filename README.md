# WeatherIQ AI - Full Stack Weather Portal

WeatherIQ AI is a full-stack application that provides real-time weather information, AI-generated weather briefings, and interactive location tools.

## ✨ Key Features

- **Live Weather & Forecasts**: Get real-time weather conditions and a 5-day forecast for any city, ZIP code, or GPS coordinate.
- **AI Weather Narrator**: Read customized, conversational weather briefings generated by Google Gemini AI based on the local weather data.
- **Search History (CRUD)**: Log in to save your previous searches. You can create, view, update, and delete your search history via a MongoDB database.
- **Interactive Maps**: View your searched locations on an embedded interactive map (Google Maps or OpenStreetMap fallback).
- **YouTube Travel Guides**: Watch the top YouTube travel guide videos automatically matched to your searched city.
- **Data Export**: Export your saved weather query logs into multiple formats, including CSV, XML, JSON, PDF, or Markdown.
- **Dark Mode UI**: Enjoy a premium, responsive glassmorphic design with both dark and light modes.
- **Smart Caching**: Uses a 1-hour MongoDB caching system to minimize external API calls and improve loading speeds.

## 🚀 Tech Stack

- **Frontend**: React (Vite), Tailwind CSS, Axios, SWR
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose ODM)
- **APIs**: OpenWeatherMap, Open-Meteo, Google Maps, YouTube Data API v3, Google Gemini AI

## ⚙️ Setup & Installation

1. **Install dependencies**:
   ```bash
   npm run install-all
   ```

2. **Configure Environment Variables**:
   Create a `.env` file in the root directory based on the `.env.example` template:
   ```env
   PORT=5000
   MONGODB_URI=your_mongodb_connection_uri
   OPENWEATHER_API_KEY=your_openweathermap_api_key
   GOOGLE_MAPS_API_KEY=your_google_maps_api_key
   YOUTUBE_API_KEY=your_youtube_api_key
   GEMINI_API_KEY=your_google_gemini_api_key
   JWT_SECRET=your_jwt_secret
   NODE_ENV=development
   CLIENT_URL=http://localhost:5173
   ```

3. **Run the Application**:
   Start both the frontend and backend concurrently:
   ```bash
   npm run dev
   ```
   - Frontend runs on `http://localhost:5173`
   - Backend runs on `http://localhost:5000`
